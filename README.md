# Android Staff Scheduling Application

A native Android application developed in Kotlin and Android Studio, achieving a Grade A (73%). Designed to streamline shift management, staff communication, and schedule tracking.

## 🚀 Key Features
* **Multi-Screen Architecture:** Clean navigation across 5 core screens (Login, Registration, Home, My Bookings, and Settings).
* **Cloud & Local Storage:** Integrated Firebase Authentication for secure sign-in and Room Database (SQLite) for robust local shift storage.
* **Productivity Tools:** Includes shift booking capabilities, CSV schedule export, and customizable settings.
* **Accessibility:** Built with dark mode support and TalkBack screen reader compatibility, achieving a 100% test pass rate across 12 rigorous test cases.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **IDE:** Android Studio
* **Backend / Auth:** Firebase Authentication
* **Local Database:** Room Database (SQLite)
* **Testing & Tools:** JUnit, Git, Android SDK

## 📥 Installation & Setup
1. Clone this repository or download the ZIP folder.
2. Open **Android Studio**.
3. Select **Open an Existing Project** and choose this folder.
4. Sync Gradle files and run the app on an Android Emulator or physical device connected via USB debugging.
